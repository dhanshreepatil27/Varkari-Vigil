## GitHub Pages deployment
1. Download and extract this ZIP.
2. Open the existing Varkari Vigil GitHub repository.
3. Upload/replace `index.html`, `style.css`, and `script.js` in the same folder where the current files live.
4. Upload the `assets` folder with `vitthal.png` (preserve the exact path `assets/vitthal.png`).
5. Commit the changes to the branch/folder configured for GitHub Pages.
6. Open the published website and hard-refresh (Ctrl+F5) if the old CSS is cached.
